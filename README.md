# Swapglow for Android

This repository only holds the built Android app of **Swapglow**, a free match-three
puzzle game. The game's source lives elsewhere; each new build is published here
automatically as a release.

**Download the newest version:**
https://github.com/LoneStarCoder/Swapglow-releases/releases/latest/download/swapglow.apk

Or visit **https://swapglow.onrender.com/download/** for screenshots and install steps,
or play in the browser at **https://swapglow.onrender.com**.

## Installing

1. Open the download link on your Android phone (Android 7 or newer).
2. When it finishes, open `swapglow.apk`.
3. If Android asks, allow your browser to install unknown apps, then tap Install.

Updates install over the old version and keep your progress.
